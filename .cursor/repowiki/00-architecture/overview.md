## 数据流向原则

1. **单向依赖**：API 层 → RPC 层 → DB/MQ，禁止反向调用
2. **跨服务仅走 RPC Client**：`pkg/` 共享库除外，严禁 `import "tjxt/apps/xxx/internal/..."`
3. **数据库隔离**：每服务独享 `tj_<domain>` 库，跨域查询走对应服务 RPC
4. **异步解耦**：订单支付、消息发送、积分变更等通过 RabbitMQ Event 解耦
